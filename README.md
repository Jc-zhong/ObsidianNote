# 使用技巧记录：

1.  使用 “\*” 符号时，如果不想被 Markdown 斜体语法影响，可以在这些特殊符号前加上转义字符 "\\" 来转义。
2.  使用 反引号 `高亮字体`    
3.  使用 双星号  **高亮字体**
4.  连续使用 3个 反引号可插入代码块，反引号后面可定义编程语言类型
```kotlin
	void test(int i){
		Log.d("TAG", "调试信息: ${i}" )
	}
```
